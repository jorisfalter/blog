The AI bots I actually run

My Claude Code bots: which run on a server, which on my laptop, and what broke along the way.

The 17 slides

Click the slides or use the arrow keys. Open full screen.

What I say on each slide

  1. The AI bots I actually run
    Recently I saw a video by Dan Martell: he uses GrokBot, a personal bot that runs all your systems and can spin out sub-bots.
  2. One personal bot that runs everything
    GrokBot is what OpenClaw intended to be. Muse (Facebook), Dot (ChatGPT) and apps like Instinct do the same. I have my own server and use Claude Code, and Claude Code bots can now message each other. What it's not good at yet: being proactive. So the bots message me on Telegram (one way, not a conversation), and the Claude app is my one point of contact.
  3. Two kinds of bots
    There are two kinds of bots, and this is why I still have this setup. Laptop: uses a lot of memory and needs the laptop on, open and powered. Server: always on, what OpenClaw intended. But websites see a data center: server bots are bad at using a browser, and more and more sites block bots. E-commerce is always the problem. On the laptop it opens a real browser and I can see it scroll.
  4. The bot does the work. I do the yes.
    The bot does the work, I do the yes. Yesterday my bot opened my old Hotmail to follow up on insurance and bank stuff, the usual suspects where people don't reply.
  5. The server bots
    These are my server bots. The bot-master. A news bot: the news I want to know, local and business. The weather. Power cuts: I live in Malawi, and when there's a power cut it files the ticket with the power company. A coach, my Tony Robbins. Two product bots. And one for how I position myself and sell. The laptop ones come later.
  6. Very simple
    News, weather, power cuts. Very simple.
  7. The coach
    The coach, my Tony Robbins: I tell him something, he texts me back.
  8. Two steps up
    The A380 bot: we discussed it in a previous video, it optimizes the SEO. Then the aidreamhouse bot, which builds AI dream houses.
  9. The laptop bots
    Now the laptop bots: the ones that need a real browser, or a lot of data.
  10. Runs on the laptop
    The e-commerce bot goes to Amazon, Bol.com, Takealot. It also looks at houses. It runs locally because it has to use the browser: from the server it gets blocked.
  11. Same story
    The sales bot is similar. It has to look on LinkedIn and other channels, and from a server they all block it.
  12. Too much data for the server
    The YouTube bot, which edits this video. The problem here: sending all the recordings to a server takes longer than just editing them locally.
  13. Moving a website off Squarespace
    Both together: I'm moving a website off Squarespace. A bot that's mostly on the laptop: the clicking in Squarespace and Google, the DNS through the Cloudflare API. I do the logins and payments.
  14. How a bot uses my browser
    How a bot uses my browser, two ways. Apple Events: the bot runs a bit of JavaScript in a Chrome tab. Fast, but blind, and its clicks are fake, so banks, captchas and payment windows say no. The Claude in Chrome extension: it sees the page and clicks for real. Always a new tab, and I log in myself.
  15. A board only works for tickets you write yourself
    Before, I had a board. Everyone likes boards; I used to be a project manager, with Jira. But a board only works for tickets you write yourself. When the bot wrote the ticket, I forgot about it. My own system: OneNote, and a paper notebook. Now every bot has its own to-do list, and the important things I write down myself.
  16. What it costs
    This costs me 24 euros a month: two servers. Claude Max is not included, and then APIs.
  17. Thanks for watching
    Thank you for watching.
